# Raven — Version Update Log

Canonical version lives in `raven-core/VERSION`. Every release bumps that file,
adds an entry here (newest first), and must pass `scripts/check-version-consistency.py`
(CI: `raven-version-consistency-check`). Historical changelogs in `docs/` are
never rewritten — this file is the roll-up index.

## v5.0.0 — 2026-08-07 — Discipline Fix Chain (major)

The engine applied its own discipline to itself. Major because the engine
tree, installer payloads, and hook wiring all changed shape.

**Engine & config integrity**
- Triplicated script trees unified: `scripts/` canonical; `raven-core/` and
  `.claude/scripts/` same-named entries are relative symlinks (−8,612
  duplicate lines). CI: `raven-engine-drift-check`.
- Single canonical hook config (`.claude/settings.json`); `hooks/hooks.json`,
  `plugin/settings.json`, `core/hooks/settings.json` are now GENERATED by
  `scripts/export-hook-configs.py`. CI: `raven-config-canon-check`.
  (Previously the installer shipped a divergent, unmaintained config.)
- CLAUDE.md hook claims now provably match wiring — PostToolUse guards
  (db-guard + secret-scan) wired for real; stale Stop-row doc corrected.
  CI: `raven-docs-reality-check`.

**Skills governance**
- `skills/MANIFEST.json`: all 62 skills registered (owner/status/purpose).
  Overlaps resolved explicitly: `oci-specialist` deprecated (superseded by
  `oracle-oci-specialist`); Andie cluster (andie/jr/guru/frames) and DB
  cluster (db-router → db-specialist → per-DB leaves) documented as
  intentional layering. CI: `raven-skill-manifest-check`.

**Model routing honesty**
- Router hook actually runs now (it never had since inception — argparse
  exited on every invocation and the error was swallowed). First prompt of
  each session discloses the session model + router state; `/router` skill
  toggles advisory Haiku-subagent delegation. The primary session model is
  never changed and Raven no longer implies otherwise.
- Embedding/reranker models excluded from routing candidates; per-tier
  PASS/FAIL routing self-check + notifications PASS/DEGRADED status in
  session-start output. `notify.py` dry-run is loud ("NOTHING WAS ACTUALLY
  SENT") and its secrets path is repo-root-anchored.

**Tokenomics trust**
- Token metering counts true per-turn deltas (checkpointed) — the
  compounding bug that once produced $101K/294M-token fictional rollups is
  fixed AND fenced: dual-path verification (independent full-transcript
  recompute) flags >5% divergence as UNVERIFIED on the dashboard and in the
  audit log, never averaged. Corrupted 2026-06/07 rollups archived.
- Per-turn, per-model cost log (`.raven/cost-log.jsonl`): estimated vs
  computed kept separate, cumulative session/month columns, one row per
  model actually observed (hook scripts cost $0 and are never logged).

**Code Map (raven-xray)**
- New `scripts/raven-xray.py`: pure-stdlib Python code-symbol map (ast +
  JSON, no database, no external deps). CLI `--callers/--callees/--impact`;
  auto-rebuilt on Stop (throttled). Dashboard "🗺️ Code Map" section with
  hotspots + client-side symbol search. Python-only, static-import
  resolution only — stated, not hidden.

**Dashboard**
- Auto-rebuilds via Stop hook (`--if-stale 15`) — no manual command needed.
  Fixed-name `dashboard-kg.html` snapshot alongside `dashboard.html`.
  Fixed a pre-existing SyntaxError that broke the whole dashboard on
  Python ≤3.11.
