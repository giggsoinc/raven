# Raven (directory edition)

Instruction-only edition of Raven: skills, slash commands and agents (Markdown). It installs no hooks, scripts or local servers and sends no data anywhere.

Install: `/plugin install raven --marketplace giggsoinc/raven`

Skills mention hook- and script-based enforcement; that lives in the full Raven install from https://github.com/giggsoinc/raven and is not part of this edition.
